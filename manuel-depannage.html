Dépannage :
les solutions, symptôme par symptôme

Les problèmes que l'on nous signale le plus, avec leur solution, classés par symptôme. Commencez toujours par les outils de diagnostic : ils trouvent la cause dans la plupart des cas.

Les outils de diagnostic

  • Connexion › 🩺 Diagnostic : 🌐 Test RJ45 (réseau et node Art-Net), 🔌 Test USB (interface DMX), 📱 Test tablette, et 🩺 Diagnostic complet (BRAD) avec 📋 Copier le rapport ou ✉️ Envoyer au support.
  • Édition › 🔬 DMX Tester : envoie des valeurs canal par canal, sans passer par le patch. Si le projecteur réagit ici, la sortie DMX marche et le problème est dans le patch.
  • Édition › 📡 Moniteur DMX : ce qui part réellement sur chaque univers.

Rien ne s'allume

  1. Sortie DMX connectée ? Connexion › 🌐 Sortie DMX : votre interface doit être choisie et connectée (voir le chapitre Sortie DMX).
  2. Un seul logiciel à la fois : fermez QLC+, Freestyler, Chataigne ou tout autre logiciel lumière.
  3. Test direct : dans le DMX Tester, montez les canaux du projecteur. S'il s'allume, la sortie fonctionne : vérifiez l'adresse et le mode dans le patch, puis la couleur posée et le fader du groupe.
  4. Câbles : changez de câble ou de port USB (sans hub), vérifiez le câble DMX et l'ordre de chaînage.
  5. Licence : après l'essai, la sortie DMX demande une licence active.

Interface USB-DMX muette ou non détectée

  • Fermez tout autre logiciel lumière : un seul logiciel peut utiliser l'interface.
  • Changez de câble ou de port USB, en évitant les hubs.
  • Rouvrez Connexion › 🌐 Sortie DMX et choisissez votre interface et son port COM. Pour un Open DMX ou une interface à puce FTDI, installez le pilote FTDI si MyStrow le propose.
  • Une interface marquée Art-Net, Node ou RDM se règle dans l'onglet Sortie Node, même branchée en USB.

Node Art-Net introuvable

  1. Node et ordinateur sur le même réseau, de préférence en câble Ethernet.
  2. Adresses IP dans la même plage (souvent 2.x.x.x ou 192.168.x.x) : l'assistant ⚙️ Configurer la connexion réseau règle l'ordinateur.
  3. MyStrow autorisé dans le pare-feu.
  4. Si MyStrow trouve le boîtier à une autre adresse, cliquez sur Utiliser [adresse].
  5. Sur Mac, vérifiez que la sortie n'est pas restée sur « USB ».

Plusieurs nodes : chacun doit avoir sa propre adresse IP et son univers (guide).

Projecteurs qui bougent seuls, mauvaises couleurs, strobe absent

  • Ils bougent ou changent tout seuls : le mode DMX réglé sur le projecteur n'est pas celui du patch (par exemple 7 canaux sur l'appareil, 9 dans le patch : les canaux se décalent et l'un tombe sur « auto » ou « son »). Prenez le même mode et vérifiez l'adresse.
  • Couleurs ou gobos faux : la fiche n'est pas la bonne. Reprenez la fiche exacte du modèle dans la bibliothèque, ou calibrez la roue de couleurs / de gobos dans le patch.
  • Le strobe ne marche pas : la fiche n'a pas le bon canal strobe/shutter, ou le mode ne correspond pas. Si c'est le Shutter qui porte le strobe, réglez la Bande strobe dans les canaux avancés du patch. Mettez aussi MyStrow à jour.
  • Un projecteur n'est pas dans la bibliothèque : créez sa fixture avec l'IA, ou envoyez-nous sa notice.

La tablette ne se connecte pas

  1. Tablette et ordinateur sur le même Wi-Fi (pas le réseau invité, pas la 4G).
  2. MyStrow autorisé dans le pare-feu de l'ordinateur.
  3. Sur Mac, erreur 403 ou 401 : désactivez le Récepteur AirPlay (Réglages Système › Général › AirDrop et Handoff).
  4. Relancez 📱 Entrée Externe et rescannez le QR code.

Mac : MyStrow ne s'ouvre pas, le DMX décroche

  • L'icône rebondit puis disparaît : vérifiez la version de macOS (Apple Silicon : macOS 13 minimum ; Intel : macOS 11 minimum) et retéléchargez la bonne version.
  • MyStrow se ferme une trentaine de secondes après l'ouverture : souvent un antivirus (AVG…). Ajoutez une exception et réinstallez.
  • Le DMX décroche quand on change de fenêtre : c'est la mise en veille des applications en arrière-plan de macOS. C'est corrigé dans les versions récentes : mettez MyStrow à jour.

Antivirus, intégrité, mises à jour

  • L'antivirus bloque ou supprime MyStrow (Trend Micro, AVG, Avast…) : fausse alerte, MyStrow est signé numériquement. Restaurez-le de la quarantaine, ajoutez une exception pour son dossier, réinstallez.
  • « L'intégrité de l'application n'a pas pu être vérifiée » : un fichier a été modifié (mise à jour interrompue, antivirus). Installez la dernière version par-dessus : shows et réglages sont conservés.
  • La mise à jour ne s'applique pas : téléchargez la dernière version sur mystrow.fr et installez-la par-dessus. Sur Mac, fermez MyStrow et remplacez l'app dans Applications.

Licence, mot de passe, réseau

  • Licence ou identifiants non reçus : spams et onglet Promotions de Gmail, puis vérifiez l'adresse tapée au paiement. Mot de passe oublié : bouton dans la fenêtre de connexion.
  • « 2 appareils maximum » : libérez un appareil depuis votre compte.
  • « Erreur réseau » ou « getaddrinfo failed » : MyStrow n'arrive pas à joindre internet. Vérifiez la connexion. La lumière n'en a pas besoin, et la licence tient jusqu'à 16 jours sans connexion.

Détails dans le chapitre Installation et licence.

Toujours bloqué ?

Écrivez-nous depuis la page Contact avec une capture d'écran et, si le problème touche la sortie DMX, le rapport du 🩺 Diagnostic complet (📋 Copier le rapport). Indiquez votre système (Windows ou Mac), votre interface DMX et le modèle du projecteur concerné : on répond vite, et la réponse rejoint souvent ce manuel.

Questions fréquentes

L'écran montre la lumière mais pas les projecteurs.

MyStrow joue, mais le DMX n'arrive pas ou n'est pas compris. Vérifiez la sortie DMX (Connexion › 🌐 Sortie DMX), puis testez le projecteur avec Édition › 🔬 DMX Tester : s'il réagit, c'est son adresse ou son mode dans le patch.

Un seul projecteur ne répond pas.

Son adresse ou son mode ne correspond pas au patch, ou le câble DMX s'arrête avant lui. Vérifiez l'adresse affichée sur l'appareil, son mode, et testez-le seul avec le DMX Tester.

Tout marchait hier, plus rien aujourd'hui.

Un autre logiciel lumière s'est peut-être ouvert au démarrage, ou l'interface a changé de port USB. Fermez les autres logiciels, rebranchez l'interface et rouvrez Connexion › 🌐 Sortie DMX.
