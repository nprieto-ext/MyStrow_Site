Controladores
e atalhos

O MyStrow toca-se com o rato, mas debaixo dos dedos é mais agradável. Este capítulo cobre todas as formas de o controlar: controladores MIDI e de DJ, Stream Deck, mesa de luz e teclado. O comando de consola está no capítulo Moving heads, o tablet no capítulo seguinte.

Controladores MIDI reconhecidos diretamente

O AKAI APC mini mk2 é o controlador de referência: a grelha de pads e os faders correspondem exatamente à superfície do MyStrow (veja o capítulo Ao vivo). O Novation Launchpad Mini MK3 também é reconhecido, tal como os perfis partilhados pela comunidade.

  1. Ligue o controlador por USB antes ou depois do arranque: o MyStrow deteta-o sozinho.
  2. Para verificar: Conexão › 🎮 Controle › 🎹 Controlador MIDI.
  3. Para mudar o que cada coluna faz, as páginas e o botão em baixo à direita: ⚙️ Configurações do controlador.

No Windows, só um programa de cada vez pode usar um controlador MIDI: feche os outros programas que o tenham aberto.

Outro controlador: o assistente «O meu controlador não é reconhecido»

Para qualquer outro controlador MIDI (ou um controlador de DJ cujos pads quer usar), abra Conexão › 🎮 Controle › 🎹 Controlador MIDI e escolha adicionar um controlador: o assistente cria o perfil em poucos minutos.

  1. Novo controlador: dê-lhe um nome e escolha a porta MIDI. Marque Meu controlador é um controlador DJ se for o caso (só os pads são usados).
  2. Estrutura do controlador: número de linhas e colunas de pads, de faders e de botões de efeito.
  3. Mapeamento dos pads: carregue em cada pad indicado; depois Mapeamento dos faders: mova cada fader de baixo para cima; depois os Botões de efeito.
  4. Teste dos LEDs: o MyStrow descobre como acender os pads do seu modelo e o utilizador clica na cor que vê.
  5. ✅ Usar meu controlador agora: o perfil é instalado e carregado em cada arranque.

Opcionalmente, Compartilhar com a comunidade envia o perfil para revisão; depois é proposto automaticamente a todos os que liguem o mesmo modelo. Exportar para um arquivo… guarda-o.

Elgato Stream Deck

Conexão › 🎮 Controle › 🎛️ Stream Deck instala o plugin MyStrow para o software Elgato Stream Deck (Instalar o plugin). Reinicie depois o software Stream Deck e procure MyStrow na coluna da direita para arrastar as suas ações para as teclas. O MyStrow tem de estar aberto para as teclas responderem.

Controlar o MyStrow a partir de uma mesa de luz (entrada DMX)

Conexão › 🎮 Controle › 🎚️ Entrada DMX (mesa): uma mesa de luz controla os grupos, as memórias e os efeitos do MyStrow por DMX ou Art-Net. Exige um node Art-Net com uma porta configurada como entrada (veja o roteamento das saídas no capítulo Saída DMX).

  • Ativar a entrada DMX e preencher a tabela Canal DMX → Controla.
  • Patch padrão: canais 1 a 7 → grupos A a G, canais 8 a 106 → MEM 1 a MEM 99.
  • Um canal também pode controlar a velocidade dos efeitos ou o volume do leitor.

Atalhos de teclado

Conexão › ⌨️ Atalhos de teclado: clique num atalho e escreva a nova combinação de teclas. ✕ apaga-o, ↺ repõe o de origem. Guarde as definições como preset para passar de uma configuração a outra; ↺ Repor predefinições repõe tudo.

Alguns atalhos fixos: Espaço para reproduzir / pausar, Ctrl+PageDown / Ctrl+PageUp para mudar de página de pads, Ctrl+Z / Ctrl+Y no patch e na linha do tempo.

Perguntas frequentes

O meu AKAI não é detetado.

Experimente outro cabo ou porta USB, feche qualquer outro programa que use o controlador e abra Conexão › 🎮 Controle › 🎹 Controlador MIDI.

O meu controlador não está na lista.

Use o assistente «O meu controlador não é reconhecido»: basta carregar em cada pad e mover cada fader. O perfil fica depois permanente nesse computador.

Posso usar dois controladores ao mesmo tempo?

Um controlador MIDI controla a superfície de pads; pode acrescentar um tablet, um comando, um Stream Deck e o teclado, que funcionam em paralelo.
