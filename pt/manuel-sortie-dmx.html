Saída DMX:
ligar o MyStrow aos projetores

Para o MyStrow controlar projetores reais, precisa de uma interface DMX entre o computador e o primeiro projetor. Este capítulo cobre tudo o que existe em Conexão › 🌐 Saída DMX e nas ferramentas de teste.

O princípio: computador → interface → projetores

O computador não envia DMX sozinho. Liga-se uma interface:

  • por USB: uma caixa USB-DMX (ENTTEC, Eurolite, Open DMX…);
  • em rede: um node Art-Net ligado por cabo Ethernet (RJ45), diretamente ou através de um switch.

Da interface sai um cabo DMX (XLR) para o primeiro projetor e depois de projetor em projetor. Uma linha DMX = um universo = 512 canais. O MyStrow gere até 4 universos.

Durante os 15 dias de experiência, a saída DMX funciona. Depois, precisa de uma licença ativa.

Abrir a janela Saída DMX

Menu Conexão › 🌐 Saída DMX. A janela começa por perguntar que interface tem, com três opções que se reconhecem pela posição do logótipo amarelo:

  • Logótipo MyStrow na face frontal: é o USB NODE DMX (ElectroConcept), a caixa do Pack MyStrow. Liga-se por USB mas fala Art-Net: o MyStrow configura-o sozinho na Saída Node, sem endereço IP a mexer.
  • Logótipo MyStrow em cima: é o MyStrow USB-DMX (MS-DMY). Ligue-o por USB, o MyStrow encontra-o sozinho. Se acabou de o ligar, clique em 🔌 Conectar.
  • Outra interface: o ecrã completo, com dois separadores, 🌐 Saída Node e 🔌 Saída DMX USB.

Interface USB-DMX (separador Saída DMX USB)

  1. Ligue a interface por USB (de preferência diretamente ao computador, sem hub).
  2. Em Interface, escolha o seu modelo: MyStrow USB-DMX (MS-DMY), Eurolite USB-DMX512 PRO (MK2), ENTTEC DMX USB Pro, ENTTEC Open DMX USB, OPTO OPEN DMX (ElectroConcept), DMXKing UltraDMX Micro ou Outra interface USB-DMX.
  3. Escolha a Porta COM que aparece quando a interface é ligada.
  4. Clique em 🔌 Conectar. Na maioria das interfaces, um LED fica verde quando a saída DMX está ativa.

A sua caixa diz Art-Net, Node ou RDM? Mesmo ligada por USB, não se configura aqui: use o separador Saída Node. É o caso do USB NODE DMX.

«Porta indisponível»: outro programa (QLC+, Freestyler, Chataigne…) está a usar a interface. Feche-o: só um programa de cada vez a pode usar.

Uma interface USB transporta um só universo. Ligar várias interfaces USB não dá vários universos: para isso são precisos nodes Art-Net.

Para um Open DMX ou uma interface com chip FTDI, instale o controlador FTDI se o MyStrow o propuser.

Node Art-Net (separador Saída Node)

  1. Ligue o node ao computador com um cabo Ethernet (evite o Wi-Fi para o DMX).
  2. Em Placa de rede, verifique a placa ligada ao node.
  3. Em Node Art-Net, escolha o seu node entre os aparelhos que responderam ou escreva o endereço IP. Procurar novamente na rede repete a deteção.
  4. Clique em 🔌 Conectar.

A rede tem de estar na mesma gama que o node. Muitos nodes Art-Net usam 2.x.x.x (as caixas ElectroConcept vêm de fábrica em 2.0.0.15), outros 192.168.x.x. O botão ⚙️ Configurar a conexão de rede lança um assistente que:

  • lhe pede para escolher a placa de rede ligada à caixa (não a Wi-Fi);
  • coloca o computador em 2.0.0.1 / máscara 255.0.0.0, automaticamente (exige direitos de administrador: 🔑 Reiniciar como administrador) ou à mão com Eu mesmo configuro, que mostra os passos do Windows;
  • testa a ligação e confirma que a caixa está ligada.

Se o MyStrow encontrar a caixa noutro endereço diferente do que procura, indica-o e propõe um botão Usar [endereço]: basta um clique, nada a mudar na rede.

No primeiro arranque, autorize o MyStrow na firewall quando o Windows pedir: caso contrário, o node não é encontrado.

Vários universos e vários nodes

No separador Saída Node, Opções avançadas › Roteamento das saídas indica, para cada linha DMX, que universo sai por ela e para que node.

  • Node de 2 ou 4 saídas: basta uma caixa, cada saída leva o seu universo.
  • Vários nodes de 1 saída: dê a cada node o seu próprio endereço IP e universo Art-Net (com o utilitário do fabricante) e escolha o node certo em cada linha da tabela.
  • Duas linhas podem levar o mesmo universo: é o espelho, para duplicar uma linha no outro lado da sala sem splitter.
  • Uma linha pode estar desativada ou servir de Entrada DMX (mesa), para controlar o MyStrow a partir de uma mesa de luz.

Depois, no patch, coloque cada projetor no universo da linha onde está ligado (os endereços recomeçam em 1 em cada universo). Passo a passo completo: vários universos com vários nodes Art-Net.

Testar a saída: DMX Tester e Monitor DMX

Editar › 🔬 DMX Tester envia valores diretamente para os canais, sem passar pelo patch. É a ferramenta para saber se um projetor recebe DMX:

  • escolha o Universo DMX e clique e arraste sobre os canais para regular o valor (Ctrl = vários canais, Shift = uma gama, roda = ±5);
  • há botões que sobem ou descem os 512 canais de uma vez;
  • TESTE POR GRUPO acende os canais por pacotes (regule Canais por grupo e depois ▶▶ Enviar os seguintes) para encontrar o endereço de um projetor;
  • os faders do controlador MIDI controlam 9 canais de cada vez;
  • ao fechar, o espetáculo é reposto tal como estava.

Editar › 📡 Monitor DMX mostra ao vivo o que sai realmente em cada universo: canais ativos, imagens por segundo, interface usada e um aviso se um universo não é emitido (por exemplo o universo 2 numa interface USB, que só leva o universo 1).

Diagnosticar uma saída muda

Menu Conexão › 🩺 Diagnóstico:

  • 🌐 Teste RJ45 (rede / Node Art-Net): verifica cabo, placa de rede, endereço IP e resposta da caixa, e propõe corrigir o que falha;
  • 🔌 Teste USB (interface DMX): verifica a interface USB e a porta;
  • 🩺 Diagnóstico completo (BRAD): encadeia todos os testes da saída Art-Net. 📋 Copiar o relatório ou ✉️ Enviar ao suporte envia-nos o resultado.

As causas mais frequentes, por ordem:

  1. outro software de iluminação aberto, que ocupa a interface;
  2. uma interface USB Art-Net (USB NODE) procurada no separador USB em vez da Saída Node;
  3. computador e node fora da mesma gama IP, ou firewall a bloquear;
  4. o projetor não está no endereço nem no modo DMX do patch (o DMX sai, mas o projetor escuta noutro sítio): o DMX Tester revela-o logo;
  5. cabo USB, porta ou cabo DMX avariado.

No Mac, se a saída ficou em «USB» quando usa um node, volte a abrir a Saída DMX e escolha Art-Net.

Perguntas frequentes

Que interface DMX devo comprar para o MyStrow?

Qualquer interface USB-DMX ou node Art-Net do mercado funciona. O mais simples é o Pack MyStrow (interface + licença): o MyStrow reconhece-o e configura-o sozinho. Para mais de um universo, escolha um node Art-Net.

Quantos projetores posso controlar?

Um universo tem 512 canais e o MyStrow gere até 4 universos (2048 canais). O número de projetores depende dos canais de cada um: um PAR de 7 canais ocupa 7, um moving head de 16 canais ocupa 16.

O Wi-Fi chega para um node Art-Net?

É possível mas desaconselhado: o Wi-Fi traz cortes e latência. Ligue o node por cabo Ethernet, diretamente ou através de um switch.

A minha interface é detetada mas nada acende.

Abra Editar › 🔬 DMX Tester e suba os canais do projetor. Se acender, a saída funciona: o endereço ou o modo DMX do patch não correspondem ao projetor. Se continuar apagado, verifique o cabo DMX e execute Conexão › 🩺 Diagnóstico.
