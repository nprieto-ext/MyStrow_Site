Un univers
par node

Votre installation dépasse 512 canaux, ou vos projecteurs sont répartis à deux endroits de la salle ? Branchez un node Art-Net par univers et dites à MyStrow lequel reçoit quoi. Jusqu'à quatre univers, sans console.

Par MyStrow · Publié le 7 octobre 2026 · ⏱ Lecture : 5 min
La configuration → Ce qui ne marche pas →
Le principe

Un univers = 512 canaux = un câble DMX

Un univers DMX transporte 512 canaux. Une lyre en mode 16 canaux en consomme seize, une barre LED pixel peut en prendre plus de cent : on arrive vite au bout. La solution est d'ajouter un deuxième univers, c'est-à-dire une deuxième ligne DMX avec ses propres 512 canaux.

MyStrow gère quatre univers. Avec un node Art-Net à quatre sorties, chaque sortie porte déjà un univers. Mais beaucoup de nodes compacts — comme les Art-Net POE 1 univers d'Electroconcept — n'en ont qu'une. Dans ce cas, on met un node par univers, tous sur le même réseau, et MyStrow envoie à chacun le sien.

Disponible à partir de MyStrow 3.2.2. Les versions précédentes envoyaient les quatre univers vers un seul boîtier : le second node restait muet.

Le matériel

Ce qu'il vous faut

  • Un node Art-Net par univers — en RJ45 ou en POE.
  • Un switch réseau entre le PC et les nodes. Pour des nodes POE, un switch POE les alimente par le câble réseau.
  • L'utilitaire du fabricant pour régler l'adresse IP et l'univers de chaque node (DMX TOOLS chez Electroconcept).
  • Un câble réseau par node, plus un pour le PC.
La configuration

Quatre étapes

1

Donnez à chaque node sa propre adresse IP

Les nodes d'un même modèle sortent d'usine avec la même adresse : à deux sur le réseau, ils se gênent. Avec l'utilitaire du fabricant, réglez-les par exemple en 2.0.0.15, 2.0.0.16, 2.0.0.17… Faites-le un boîtier à la fois, seul branché.

2

Réglez l'univers de chaque node

Le premier node sur l'univers Art-Net 0, le deuxième sur l'univers 1, et ainsi de suite. C'est ce numéro que MyStrow affiche dans la colonne « Art-Net » du tableau. Certains utilitaires comptent à partir de 1 : si un node reste muet, c'est la première chose à vérifier.

3

Associez chaque ligne à son node

Dans MyStrow, ouvrez Connexion ▸ Sortie DMX, onglet Sortie Node, et cliquez sur ↻ pour trouver les nodes. Choisissez le premier comme node principal. Dans le tableau « Aiguillage des sorties », colonne Envoyé au node, choisissez le deuxième node sur la ligne DMX 2, le troisième sur la ligne DMX 3… puis cliquez sur Connecter.

4

Patchez vos projecteurs dans le bon univers

Dans le patch, les projecteurs câblés sur le premier node vont en Univers 1, ceux du deuxième en Univers 2. Les adresses DMX repartent de 1 dans chaque univers.

Exemple

Une ligne peut aussi envoyer le même univers qu'une autre : c'est le mode miroir, pratique pour doubler une ligne DMX à l'autre bout de la salle sans splitter.

Les limites

Ce qui ne marche pas

MatérielPlusieurs univers ?Pourquoi
Nodes Art-Net RJ45 ou POE✅ Jusqu'à 4Chacun a son adresse sur le réseau : MyStrow envoie à chaque node son univers.
Node Art-Net à 2 ou 4 sorties✅ Jusqu'à 4Un seul boîtier suffit : chaque sortie porte déjà un univers.
Interfaces USB-DMX (Open DMX, Enttec, MS-DMX…)❌ Un seulMyStrow pilote un seul port USB à la fois. Brancher quatre interfaces ne donne pas quatre univers.
Plusieurs USB NODE Electroconcept⚠️ DéconseilléChaque boîtier crée sa propre carte réseau, tous à la même adresse d'usine : le PC ne sait plus à qui parler.
Dépannage

Si un node reste muet

  • Le deuxième node ne s'allume pas : vérifiez que son univers correspond au numéro « Art-Net » de sa ligne. Si l'utilitaire compte à partir de 1, essayez le numéro suivant.
  • Un seul node répond à la recherche : les deux ont probablement la même adresse IP. Changez-en une, boîtier seul branché.
  • Les projecteurs du node 2 réagissent aux réglages du node 1 : ils sont patchés dans le mauvais univers. Ouvrez le patch et passez-les en Univers 2.
  • Aucun node ne répond : la carte réseau du PC doit être sur le réseau 2.x.x.x. Le guide de configuration du node détaille ce réglage.
