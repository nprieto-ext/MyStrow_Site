Troubleshooting:
solutions, symptom by symptom

The problems reported to us most often, with their solution, sorted by symptom. Always start with the diagnostic tools: they find the cause in most cases.

The diagnostic tools

  • Connection › 🩺 Diagnostics: 🌐 RJ45 test (network / Art-Net Node), 🔌 USB test (DMX interface), 📱 Tablet test, and 🩺 Full diagnostic (BRAD) with 📋 Copy the report or ✉️ Send to support.
  • Edit › 🔬 DMX Tester: sends values channel by channel, bypassing the patch. If the fixture reacts here, DMX output works and the problem is in the patch.
  • Edit › 📡 DMX Monitor: what actually goes out on each universe.

Nothing lights up

  1. DMX output connected? Connection › 🌐 DMX Output: your interface must be chosen and connected (see the DMX output chapter).
  2. One program at a time: close QLC+, Freestyler, Chataigne or any other lighting software.
  3. Direct test: in the DMX Tester, raise the fixture's channels. If it lights, the output works: check the address and mode in the patch, then the colour set and the group's fader.
  4. Cables: try another USB cable or port (no hub), check the DMX cable and the daisy-chain order.
  5. License: after the trial, DMX output requires an active license.

USB-DMX interface silent or not detected

  • Close any other lighting software: only one program can use the interface.
  • Try another USB cable or port, avoiding hubs.
  • Reopen Connection › 🌐 DMX Output and choose your interface and its COM port. For an Open DMX or an FTDI-chip interface, install the FTDI driver if MyStrow offers it.
  • An interface marked Art-Net, Node or RDM is set up in the Node output tab, even when plugged in over USB.

Art-Net node not found

  1. Node and computer on the same network, preferably by Ethernet cable.
  2. IP addresses in the same range (often 2.x.x.x or 192.168.x.x): the ⚙️ Set up the network connection wizard sets up the computer.
  3. MyStrow allowed through the firewall.
  4. If MyStrow finds the box at another address, click Use [address].
  5. On Mac, check that the output didn't stay on “USB”.

Several nodes: each must have its own IP address and universe (guide).

Fixtures moving on their own, wrong colours, no strobe

  • They move or change on their own: the DMX mode set on the fixture isn't the one in the patch (for example 7 channels on the device, 9 in the patch: the channels shift and one lands on “auto” or “sound”). Use the same mode and check the address.
  • Wrong colours or gobos: the profile isn't the right one. Take the model's exact profile from the library, or calibrate the colour / gobo wheel in the patch.
  • Strobe doesn't work: the profile doesn't have the right strobe/shutter channel, or the mode doesn't match. If the Shutter carries the strobe, set the Strobe band in the patch's advanced channels. Also update MyStrow.
  • A fixture isn't in the library: create its profile with AI, or send us its manual.

The tablet won't connect

  1. Tablet and computer on the same Wi-Fi (not the guest network, not 4G).
  2. MyStrow allowed through the computer's firewall.
  3. On Mac, 403 or 401 error: turn off the AirPlay Receiver (System Settings › General › AirDrop & Handoff).
  4. Restart 📱 External Input and scan the QR code again.

Mac: MyStrow won't open, DMX drops out

  • The icon bounces then disappears: check the macOS version (Apple Silicon: macOS 13 minimum; Intel: macOS 11 minimum) and download the right version again.
  • MyStrow closes about thirty seconds after opening: often an antivirus (AVG…). Add an exception and reinstall.
  • DMX drops out when you switch windows: that's macOS putting background apps to sleep. It's fixed in recent versions: update MyStrow.

Antivirus, integrity, updates

  • The antivirus blocks or deletes MyStrow (Trend Micro, AVG, Avast…): false alarm, MyStrow is digitally signed. Restore it from quarantine, add an exception for its folder, reinstall.
  • “The application's integrity could not be verified”: a file was modified (interrupted update, antivirus). Install the latest version over the top: shows and settings are kept.
  • The update won't apply: download the latest version from mystrow.fr and install it over the top. On Mac, close MyStrow and replace the app in Applications.

License, password, network

  • License or credentials not received: spam and Gmail's Promotions tab, then check the address typed at checkout. Forgotten password: button in the login window.
  • “2 devices maximum”: free up a device from your account.
  • “Network error” or “getaddrinfo failed”: MyStrow can't reach the internet. Check the connection. The light doesn't need it, and the license holds for up to 16 days offline.

Details in the Installation and license chapter.

Still stuck?

Write to us from the Contact page with a screenshot and, if the problem concerns the DMX output, the 🩺 Full diagnostic report (📋 Copy the report). Tell us your system (Windows or Mac), your DMX interface and the model of the fixture concerned: we answer quickly, and the answer often ends up in this manual.

Frequently asked questions

The screen shows light but the fixtures don't.

MyStrow is playing, but DMX isn't arriving or isn't understood. Check the DMX output (Connection › 🌐 DMX Output), then test the fixture with Edit › 🔬 DMX Tester: if it reacts, it's its address or mode in the patch.

Only one fixture doesn't respond.

Its address or mode doesn't match the patch, or the DMX cable stops before it. Check the address shown on the device, its mode, and test it on its own with the DMX Tester.

Everything worked yesterday, nothing today.

Another lighting program may have opened at startup, or the interface changed USB port. Close other programs, plug the interface back in and reopen Connection › 🌐 DMX Output.
