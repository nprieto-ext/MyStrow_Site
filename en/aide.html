Getting started

Is MyStrow free?

MyStrow can be tried free for 15 days, with no credit card and with DMX output. After that, a license is required: monthly or annual subscription, or a lifetime license. Current prices are on the Shop page.

The software runs on Windows 10/11 and macOS (Intel Mac: macOS 11 or later; Apple Silicon Mac M1 to M5: macOS 13 or later). Download: mystrow.fr/en/download.

How do I connect my DMX lights to the computer?

You need a DMX interface between the computer and the first fixture: either a USB-DMX box, or an Art-Net node connected to the network (Ethernet cable). The fixtures are then daisy-chained with DMX (XLR) cables.

  1. Plug in the interface, then open Connection › 🌐 DMX Output.
  2. Choose your interface in the list: MyStrow detects USB boxes and the Art-Net nodes on the network.
  3. If in doubt, run Connection › 🩺 Diagnostics (USB test or network test).

Details for each interface model: setting up an Art-Net node or a USB-DMX interface.

How do I add my fixtures to MyStrow (the DMX patch)?

Open Edit › 🔌 DMX Patch. The “patch” tells MyStrow which fixtures you have and which DMX address each one listens to.

  1. Choose 🧙 Wizard (guided step by step) or 📄 Empty patch.
  2. Look up the brand and model of each fixture in the library (more than 5,000 profiles).
  3. Select the same DMX mode as the one set on the fixture (its channel count, shown in its menu or set by its DIP switches).
  4. Check that the DMX address in the patch is the one set on the fixture.

For moving heads: patching and programming moving heads.

My fixture isn't in the library. How do I create it?

Have an AI create it from the user manual: in DMX Patch, menu 🛠 Create your fixture › ✦ Create your fixture with AI.

  1. Click 📋 Copy the prompt.
  2. Paste it into ChatGPT, Gemini or Claude and attach the fixture's manual (PDF or a photo of the DMX channel table).
  3. Paste the AI's answer back into MyStrow and click ✦ Create the fixture.

Full guide: create a DMX fixture with AI. You can also import a file or build it by hand: importing a DMX fixture.

Playing live

How do I turn my lights on in a colour?

Click a colour pad in the column of the group you want, then raise that group's fader. Each pad column is a group of fixtures (front, back, sides…), each pad a colour.

With an AKAI APC mini controller, it's the same grid, physically. Without a controller, everything works with the mouse or from a tablet. To start from scratch: getting started with MyStrow.

How do I record a look (a memory) and recall it?

Set up the look you want, click the 🔴 REC Memory button, then click the memory pad to store it on. Pressing that pad recalls the look.

  • Right-clicking a memory pad opens its settings: fade time and 🎛️ Behaviour: Switch (pressing sets the memory), Flash (it only stays while the pad is held) or Flash solo (same, cutting the other memories while held).
  • To start with ready-made memories: File › 🏠 Load default memories.

How do I create a lighting effect (chase, wave, strobe, moving-head motion)?

Open Edit › 🎨 Effect editor. Start from a factory effect in the list, or click ＋ Add an effect › Create the effect myself.

  1. An effect is made of layers. Each layer animates a CHANNEL (intensity, colour, Pan/Tilt…) following a SHAPE (Sine, Flash, One by one…).
  2. Set the speed (SPD), the amplitude (AMP) and the offset between fixtures (OFS: this is what creates the chase).
  3. Turn on ⏺ Live output to see the effect on your real fixtures while you adjust it.
  4. Under ASSIGN, click a button E1 to E8 to put it on an effect button of the main window, then Save effect.

The detailed tutorial, with ready-to-use recipes: creating a lighting effect in MyStrow.

How do I move my moving heads?

Two ways: by hand from the lighting plan (drag the moving head's point), or with an effect whose layer uses the Pan/Tilt channel (Circle, Eight, Infinity, Swing, Pendulum, Square shapes).

For fixed positions you can recall (singer, audience, drums…), record them with 🔴 REC Memory on a POS pad. Remember to set the movement limits in the patch. Guide: patching and programming moving heads. You can also drive them with a game controller.

How do I make the lights react to music without programming anything?

Two modes do it on their own:

  • AI Light: in the playlist, set a track to 💡 AI Light mode. MyStrow analyses the sound (energy, rhythm, BPM) and generates colours and intensities live. Settings: Edit › 💡 AI Light.
  • Live mode (View › Live mode): MyStrow listens to an audio source (Spotify, DJ software, microphone) and follows the beat, build-ups and drops.

More: AI Light · lights synced to Spotify · with DJ software.

Building an automatic show

How do I program a light show on a song (REC Light)?

Add the track to the playlist, then right-click › 🔴 REC Light: the track's timeline editor opens, with one track per fixture group and the song's waveform.

  1. Drag colours, memories, effects or moving-head positions from the library onto the tracks, lining them up with the waveform.
  2. Or let Tools › ✨ AI Generation lay down a first version, then touch it up.
  3. Click 💾 Save: the track switches to ▶ Light sequence mode and replays the show identically every time it plays.
  4. Save the show (File › 💾 Save Show).

All the details: manual, Playlist and REC Light chapter.

How do I fix a sequence I've already made?

Reopen it with right-click on the track › 🔴 REC Light. Each block can be moved, stretched, cut (✂️ Cut in two, C tool) or deleted; right-clicking a block sets its intensity, colour and fades.

A sequence can also be exported and re-imported (⬆ Export REC Light / ⬇ Import REC Light, .lrec files).

How do I prepare and run a whole show?

Put all your media in the playlist, in order, each with its light mode (🎛 Manual, 💡 AI Light or ▶ Light sequence), then save the show: File › 💾 Save Show (a .tui file containing the playlist, patch and sequences).

  • Right-click a media item: loop, fade in/out, “launch with previous sound”, pause.
  • Start at a set time: File › Scheduled start.
  • Audio and video are played by MyStrow: audio and video player.
Controllers, tablet and assistant

How do I use a MIDI controller (AKAI APC mini, Launchpad)?

Plug it in over USB: MyStrow recognises it on its own. To check or configure it: Connection › 🎮 Control › 🎹 Contrôleur MIDI (MIDI controller), and ⚙️ Controller settings to change what each pad does.

The AKAI APC mini mk2 is the recommended model (pad grid and faders already mapped). The controller is optional. Hardware: Shop.

How do I control MyStrow from a tablet or phone?

Open Connection › 🎮 Control › 📱 External Input, click Activate and scan the QR code with the tablet, connected to the same Wi-Fi as the computer. Nothing to install.

Guide: controlling MyStrow from a tablet. There is also a tablet app that works without a PC.

Can I control MyStrow by talking to an AI?

Yes. With Claude Desktop and the MyStrow extension, you ask in plain language (“set the front wash to blue”, “start the strobe effect”) and MyStrow does it. Setup: controlling your lights with the AI assistant.

Troubleshooting

My lights don't turn on. What should I check?

  1. DMX output: in Connection › 🌐 DMX Output, your interface must be selected and connected.
  2. One program at a time: close QLC+, Freestyler or any other lighting software that is using the interface.
  3. Address and mode: the DMX address and mode (channel count) set on the fixture must match the patch.
  4. Cable and port: try another USB cable or port (avoid hubs), check the DMX cable.
  5. Run Connection › 🩺 Diagnostics: it tests the USB interface or the network.

During the 15-day trial, DMX output works. Once the trial is over, it requires an active license.

My lights change colour or move on their own.

Almost always, the DMX mode set on the fixture isn't the one in the patch. Example: fixture in 7-channel mode, patched as 9 channels: the channels shift and one lands on “auto” or “sound”.

Look at the mode shown on the fixture, choose the same one in Edit › 🔌 DMX Patch and check the address. If colours or gobos are wrong, the profile is not the right one: use the exact profile of the model, or calibrate the colour wheel in the patch.

My Art-Net node isn't found.

  1. The node and the computer must be on the same network, preferably by Ethernet cable rather than Wi-Fi.
  2. Their IP addresses must be in the same range (often 2.x.x.x or 192.168.x.x: see the node's display or manual).
  3. Allow MyStrow through the firewall (Windows asks on first launch).
  4. In Connection › 🌐 DMX Output, choose Art-Net and select the node.

Several nodes: several DMX universes.

Strobe doesn't work on a fixture.

The fixture's profile doesn't have the right strobe/shutter channel, or the fixture isn't in the patched mode. Check the mode in the patch and update MyStrow (several profiles have been fixed). Otherwise, send us the fixture's manual via the Contact page and we'll fix the profile.

The tablet won't connect.

  1. The tablet and the computer must be on the same Wi-Fi (not the guest network, not 4G).
  2. Allow MyStrow through the computer's firewall.
  3. On Mac, if the page shows a 403 or 401 error: turn off the AirPlay Receiver (System Settings › General › AirDrop & Handoff › AirPlay Receiver), which uses the same port.
  4. Restart 📱 External Input and scan the QR code again.

MyStrow won't open, or my antivirus blocks it.

Antivirus (Trend Micro, AVG, Avast…): it's a false alarm, MyStrow is digitally signed. Restore it from quarantine, add an exception for its folder, then reinstall it from mystrow.fr.

On Mac, if the icon bounces then disappears: check your macOS version (Apple Silicon: macOS 13 minimum; Intel: macOS 11 minimum) and download the right file again (Apple Silicon or Intel).

The message “The application's integrity could not be verified” is fixed by installing the latest version over the top: shows and settings are kept.

I haven't received my license or my password.

Check your spam folder (and the Promotions tab in Gmail), then check the address typed at checkout: one typo and the email goes nowhere. Forgotten password: 🔑 Forgot password? button in MyStrow's login window. Still nothing: contact us.
