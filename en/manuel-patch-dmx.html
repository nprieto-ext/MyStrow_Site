DMX patch:
declaring your fixtures

The patch tells MyStrow which fixtures you have, which DMX address each one listens to and which group it plays in. Everything happens in Edit › 🔌 DMX Patch.

The DMX Patch window

Menu Edit › 🔌 DMX Patch. On the left, the list of devices (sortable by Address, Name or Group, with a filter field). On the right, the selected device's sheet. A 🎭 Lighting plan tab shows the fixtures placed on stage.

The top bar holds: 📁 File (new patch, save, import, export), ✏️ Edit (undo Ctrl+Z, redo Ctrl+Y, ⚡ Auto address), 🛠 Create your fixture and ➕ Add. Remember to 💾 Save before closing: MyStrow warns you if changes are unsaved.

Starting from scratch: the wizard

📁 File › ✨ New patch offers two starting points:

  • 🧙 Wizard: step by step, it asks how many fixtures you have on the front, back light, sides, top light, how many moving heads, smoke, haze and spark machines and flame projectors. For each category, you pick the fixture (Choose fixture…). It builds the patch and the lighting plan, then Configure applies it.
  • 📄 Empty patch: you add devices one by one.

🏠 Default patch reloads the demo patch.

Adding a fixture from the library

  1. Click ➕ Add: the Fixture Library opens (more than 5,000 models).
  2. Type the brand or model in the search field, or filter by manufacturer.
  3. Choose the DMX mode: exactly the same as the one set on the fixture (its channel count, in its menu or manual). The mode's channel list is shown so you can check.
  4. Enter the Quantity and, if you want, a custom name, then Add. Devices are numbered and placed one after another.

The library's My projectors tab contains the fixtures you've created or imported.

LED bars and pixel matrices are added the same way. Their sheet gains a Pixel layout section: rows × columns, wiring by rows or serpentine, ⇄ Reverse the order (bar hung the other way round) and real size for the 2D and 3D plan.

A device's sheet: name, group, universe, address

  • Identity: name and type of the device.
  • Group: devices in the same group are driven together, by the same pad column and the same fader. The base groups are A = Front, B = Sides, C = Back, D, E, F = Top 1 to 3, plus free groups G and H, and dedicated families (moving heads, bars, strobes, smoke, audience).
  • Universe: the DMX line the device is cabled on (512 addresses per universe). With few fixtures, keep everything on universe 1. See the DMX output chapter for multiple universes.
  • DMX patch: the start address. It must match the one set on the fixture. For a fixture with DIP switches, the DIP switches section (in the advanced channels) draws switches 1 to 9 to set ON for that address.
  • DMX profile: the list of channels in order, taken from the fixture profile.

Multiple selection (Ctrl / Shift): ✏ Rename in series (“PAR Front” gives “PAR Front 1”, “PAR Front 2”…), ⬡ Group to change the group of all at once, 🔄 Replace with another fixture from the library, 🗑 Delete. 🎯 Locate selects the device on the lighting plan.

DMX addresses: Auto address and overlaps

Each device uses as many addresses as its mode has channels: a 7-channel PAR at address 1 occupies 1 to 7, the next one starts at 8 at the earliest.

If two devices overlap, MyStrow shows it. ✏️ Edit › ⚡ Auto address recalculates all addresses one after another, with no gaps. Then remember to set the new addresses on the fixtures.

Two identical fixtures at the same address do exactly the same thing: that's intentional when you want to drive them as one.

Settings for moving heads and moving devices

  • Movement limits: the area the head is allowed to reach (so it never blinds the audience or aims at a wall). Drag the point to test live. Apply to all moving heads of this model or to all moving heads saves you doing it again.
  • Mechanical range: the degrees covered by the full Pan and Tilt travel (540° / 270° on most moving heads, see the manual). It's used by the 3D plan and the shape of circle effects.
  • ↔ Pan inverted, ↕ Tilt inverted, ⇄ Swap Pan/Tilt: for a head hung upside down or turned.
  • 🎨 Calibrate the color wheel and 🎯 Calibrate the gobo wheel: match each colour or gobo to its real DMX value, then Copy this wheel to… the other devices of the same model. MyStrow offers calibration when you add colour-wheel moving heads.

Advanced channels: usable range, strobe, LED ring

  • Usable range: limits a channel to part of its travel. Useful when the top of a channel triggers an automatic program (lasers, Pan/Tilt on some devices): the whole fader travel is squeezed into the allowed range. Double-click: full travel.
  • Strobe band: when a device has no dedicated strobe channel and the Shutter carries the strobe, set the strobe's DMX range here (often around 64-95, see the manual). ⚡ Test makes the device strobe so you can check.
  • 💫 Ring follows the show: a moving head's LED ring takes the beam's colour, level and strobe. Untick to drive it by hand.
  • Right-clicking an advanced channel sets its default value.

A fixture missing from the library

Three solutions, from quickest to slowest:

  1. With an AI: 🛠 Create your fixture › ✦ Create your fixture with AI, copy the prompt, give it to ChatGPT, Gemini or Claude with the fixture's manual, paste the answer back. Guide: a fixture in 15 seconds.
  2. By importing a file: in the library, 📥 Import accepts MyStrow formats (.mft, .json, .mystrow), GrandMA XML (.xml, downloadable from FixtureShare) and QLC+ (.qxf). If the file contains several modes, MyStrow asks which one to import.
  3. By hand: 🛠 Create your fixture manually, then declare the channels one by one. Guide: importing or creating a fixture.

A created fixture joins My projectors. In the patch list, a device can also be duplicated or exported to share it.

Importing, exporting and printing the patch

  • 📂 Import patch reads a MyStrow patch (.msp, .json), a QLC+ workspace (.qxw) or a spreadsheet (.csv, .tsv, .txt, .xlsx, columns Name, Brand, Model, Mode, Universe, Address, Channels, Group). A review window shows each device (recognised, approximated, generic) before importing, replacing the current patch or adding to it.
  • 📤 Export patch (.msp) to reuse it on another computer.
  • 📊 Export to Excel and 🖨️ Export lighting plot (PDF): the patch sheet to hand to technicians, with address conflicts flagged.

The patch is also saved in the show file (.tui) and follows your MyStrow account from one computer to another.

Frequently asked questions

My fixture changes colour or moves on its own.

The DMX mode set on the fixture isn't the one in the patch: the channels are shifted and one lands on “auto” or “sound”. Choose in the patch the same mode as the one shown on the fixture, and check the address.

Which address should I give my fixtures?

Any address, as long as the patch address and the one set on the fixture match and two different devices don't overlap. The simplest: ⚡ Auto address, then copy the addresses onto the fixtures.

I don't know my fixture's mode.

It's shown in the fixture's menu (often “7CH”, “d7”, “CH 9”…) or in its manual. Failing that, take the fullest mode and check with Edit › 🔬 DMX Tester.

Can I bring in my QLC+ patch?

Yes: 📁 File › 📂 Import patch reads a QLC+ workspace (.qxw). The review window shows which devices were recognised and which need checking.
