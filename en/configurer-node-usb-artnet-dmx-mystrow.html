Your setup

01 Configurator : your hardware, your procedure

Two questions, then the exact procedure. Everything then happens in a single window in the software : Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output.

1 What is written on your box ?

Turn it over : the model name is printed on the top or on the connector face. Click the one that matches.

Another name ? Then look at the connectors on the box :
Torn between the last two ? Go with “open” : if the box is in fact a Pro, the output simply will not start and all you have to do is change the “Interface” line in the software. No risk to the hardware.
2 On which computer ?
Select an interface and a system to display the procedure.

Art-Net node

Windows
1

Plug in the two cables

One RJ45 cable straight between the PC and the node (no switch, no Wi-Fi), and the power : square USB-B or USB-C depending on the model. Check that the LED on the box lights up.

2

Set up the node in its utility

For ElectroConcept nodes, with the box plugged in and powered, open dmx-tools.electroconcept.fr and enter :

DMX Parameters
DMX Mode: OUT · Universe OUT: 0 · Universe IN: 1 · OUT Mode: Fixed · FPS Fixed: 40
Network Parameters
Node IP: 2.0.0.15 · DHCP IP: 2.0.0.2 · Netmask: 255.0.0.0

Confirm, then unplug and replug the USB : the node restarts on its new address. It ships set to 2.0.0.1, and 2.0.0.15 is the address MyStrow targets by default — stick to it and you will have nothing to enter in the software.

On another node (ENTTEC ODE, DMXKing eDMX…), the utility changes but the settings are the same : Art-Net protocol, output set to OUT, universe 0, IP 2.0.0.15 / netmask 255.0.0.0.

3

Set the PC's network adapter to 2.0.0.1

In MyStrow : Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🌐 Node output, button ⚙️ Configure the network connection. The wizard checks the cables, lists the Ethernet adapters, and the Configure automatically ✓ button applies 2.0.0.1 / 255.0.0.0 to the one you point at.

Automatic configuration requires administrator rights. If it fails, the wizard falls back to the manual page : button 🔑 Restart as administrator, or set it by hand — right-click the adapter ▸ Properties ▸ TCP/IPv4 ▸ Properties ▸ “Use the following IP address” ▸ 2.0.0.1, netmask 255.0.0.0, gateway empty.

Order matters. Do step 2 before this one : the node ships from the factory on 2.0.0.1, the very address the wizard is about to give your PC. Both would claim it at once, and Windows may then disable the adapter, reporting a duplicate address.
4

Allow MyStrow through the firewall

On the first transmission, Windows shows an authorisation prompt : tick Private networks and confirm. Art-Net goes out over UDP on port 6454 ; if you refuse, the prompt never comes back and the node stays silent.

Already refused it by mistake ? Windows Defender Firewall ▸ Allow an app ▸ tick MyStrow for private networks.
5

Connect, then route the outputs

Tab 🌐 Node output : the status turns green as soon as the box answers, then click 🔌 Connect. In the Output routingtable, say which universe goes to which physical socket (see Universes & routing).

Quick check : Connection ▸ 🩺 Diagnostics ▸ 🌐 RJ45 test (network / Art-Net node) checks the network adapter, the ping and the node's Art-Net reply.

Wi-Fi : avoid it. Art-Net copes badly with packet loss and the variable latency of a wireless network — the lights “stutter”. Wired for the node, Wi-Fi for the control tablet.

Art-Net node

macOS
1

Plug in the two cables

One RJ45 straight between the Mac and the node, and the power (USB-B or USB-C depending on the model). With no Ethernet port, use a USB-C → Ethernet adapter : it shows up as a full network adapter.

2

Set up the node in its utility

For ElectroConcept nodes, with the box plugged in and powered, open dmx-tools.electroconcept.fr (Safari or Chrome) and enter :

DMX Parameters
DMX Mode: OUT · Universe OUT: 0 · Universe IN: 1 · OUT Mode: Fixed · FPS Fixed: 40
Network Parameters
Node IP: 2.0.0.15 · DHCP IP: 2.0.0.2 · Netmask: 255.0.0.0

Confirm, then unplug and replug the USB. 2.0.0.15 is the address MyStrow targets by default. On another node the names change but not the values : Art-Net, OUT, universe 0, 2.0.0.15 / 255.0.0.0.

3

Set the Mac's IP by hand

System Settings ▸ Network ▸ select the Ethernet interface (or the USB-C adapter) ▸ Details… ▸ tab TCP/IP ▸ Configure IPv4 : Manually.

IP address
2.0.0.1
Subnet mask
255.0.0.0
Router
(leave empty)

Then OK ▸ Apply. In MyStrow, the wizard's 📂 Open network connections button takes you straight to that panel.

On Mac, there is no automatic configuration. The wizard's “Configure automatically” button relies on Windows commands : on macOS, the manual entry above is what counts.
The Mac can stay connected to Wi-Fi for the internet : traffic to 2.0.0.15 will leave through the Ethernet port, which carries the 2.x addressing plan.
4

Allow MyStrow on the local network

System Settings ▸ Privacy & Security ▸ Local Network ▸ enable MyStrow. macOS asks the question on first launch ; if it was refused, this is where you fix it.

Pitfall no. 1 on Mac. Without that permission, macOS blocks Art-Net silently : no error, no message — the node simply never answers and the output stays dead. After enabling it, quit and relaunch MyStrow.
5

Connect, then route the outputs

Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🌐 Node output : green status, then 🔌 Connect. Then set the Output routing table (see Universes & routing).

Quick check : Connection ▸ 🩺 Diagnostics ▸ 🌐 RJ45 test (network / Art-Net node).

Wi-Fi : avoid it for the node itself — packet loss and variable latency make the lights “stutter”. Wired for DMX, Wi-Fi for the control tablet.

USB NODE DMX

Windows

This box is not a node like the others. It has neither an RJ45 socket nor a separate power supply : a single USB cable carries both power and network. Windows sees it as an extra network adapter, and the box itself hands your computer its IP address. So there is no address to type in on your PC.

1

Plug the USB cable in, then wait

A single cable, from the PC to the box. Windows then has to install the network adapter it contains : allow about ten seconds, sometimes more on the very first connection.

It shows up under a name that depends on the driver in use — « Electroconcept USB Node » or « UsbNcm Host Device ». That is normal, both mean your box.
2

Set the node up in DMX TOOLS

With the box plugged in, open dmx-tools.electroconcept.fr and enter :

DMX Parameters
DMX Mode: OUT · Universe OUT: 0 · Universe IN: 1 · OUT Mode: Fixed · FPS Fixed: 40
Network Parameters
Node IP: 2.0.0.15 · DHCP IP: 2.0.0.2 · Netmask: 255.0.0.0

Confirm, then unplug and replug the USB. The box ships from the factory on 2.0.0.1 ; MyStrow, for its part, talks to 2.0.0.15. That is the whole point of this step.

3

Leave the network adapter alone

Unlike an RJ45 node, there is nothing to configure here : the box assigns an address to your PC itself (2.0.0.2), and it is already the right one. Leave the adapter on « Obtain an IP address automatically ».

Do not run « Configure automatically » before step 2. That wizard assigns 2.0.0.1 to your PC — the box's own factory address. Until the node has moved to 2.0.0.15, both claim the same address and Windows may disable the adapter. After step 2 there is no more conflict : the wizard becomes harmless again, simply useless.
4

Allow MyStrow through the firewall

On the first transmission, Windows shows a permission prompt : tick Private networks and confirm. Art-Net goes out over UDP on port 6454 ; once refused, the prompt never comes back and the node stays silent.

Already refused by mistake ? Windows Defender Firewall ▸ Allow an app ▸ tick MyStrow for private networks.
5

Connect

In MyStrow : Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, 🌐 Node output tab. The status turns green as soon as the box answers, then click 🔌 Connect.

The box's DMX indicator is your best witness : it only lights up when data actually arrives. Dark while MyStrow says « connected » means the frames are going to the wrong address — go back to step 2.

One DMX socket only. This model carries a single physical output and broadcasts universe 1 only. MyStrow's routing table still lets you choose which universe goes there, but one at a time : if your fixtures are patched to universe 2, 3 or 4, set DMX 1 ← Universe 2 (see Universes & routing) or repatch them to universe 1.

USB NODE DMX

macOS

This is the simplest box on a Mac. A single USB cable carries power and network. macOS sees it as an extra network interface, and the box hands it its address itself : unlike an RJ45 node, there is no address to type in under Network settings.

1

Plug the USB cable in, then wait

A single cable, from the Mac to the box. Allow about ten seconds before the interface appears under System Settings ▸ Network.

On a recent Mac (USB-C only), use a powered adapter or a direct port : this box draws its power from USB, and an overloaded passive hub will make it drop out mid-show.
2

Set the node up in DMX TOOLS

With the box plugged in, open dmx-tools.electroconcept.fr and enter :

DMX Parameters
DMX Mode: OUT · Universe OUT: 0 · Universe IN: 1 · OUT Mode: Fixed · FPS Fixed: 40
Network Parameters
Node IP: 2.0.0.15 · DHCP IP: 2.0.0.2 · Netmask: 255.0.0.0

Confirm, then unplug and replug the USB. The box ships on 2.0.0.1, and MyStrow talks to 2.0.0.15.

3

Leave the interface on automatic

Under System Settings ▸ Network, the box's interface must stay on « Using DHCP ». It takes the 2.0.0.2 address the box gives it : that is the right one, do not force it to manual.

The Mac can stay on Wi-Fi for the internet : traffic to 2.0.0.15 will leave through the box's interface, which carries the 2.x addressing plan.
4

Connect

In MyStrow : Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, 🌐 Node output tab. The status turns green as soon as the box answers, then 🔌 Connect. macOS may ask for permission to accept incoming connections : accept.

The box's DMX indicator only lights up when data actually arrives. Dark while MyStrow says « connected », go back to step 2.

One DMX socket only. This model carries a single physical output and broadcasts universe 1 only. If your fixtures are patched to universe 2, 3 or 4, set DMX 1 ← Universe 2 in the routing table (see Universes & routing) or repatch them to universe 1.

“Pro” USB interface (ENTTEC DMX USB Pro, Eurolite MK2)

Windows
1

Plug in before opening the window

Into a direct USB port on the PC, preferably at the back on a tower ; avoid unpowered hubs. Plug it in before opening the DMX output window, so the port is already listed.

2

Check the driver

These boxes use an FTDI chip : Windows installs the driver by itself in the vast majority of cases. To check : Device Manager ▸ Ports (COM & LPT) — you should see a line like USB Serial Port (COM4).

Nothing shows up, or a yellow exclamation mark ? Install the FTDI VCP driver (ftdichip.com) or the manufacturer's one, then plug the box back in.

3

Select and connect

Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🔌 USB DMX output :

  • Interface : “ENTTEC DMX USB Pro” or “Eurolite USB-DMX512 PRO (MK2)”.
  • COM port : the one belonging to the interface — FTDI chips are marked with a ★. The ↺ button re-runs the detection.
  • 🔌 Connect : this button, and only this button, actually switches the software's output over. Opening the tab is not enough.
Nothing to choose on the protocol side : MyStrow talks to these boxes with a packet protocol, and the internal microcontroller builds the DMX frames. That is what makes them so stable.
4

Check

The LED on the box turns green when the output is active. To go further : Connection ▸ 🩺 Diagnostics ▸ 🔌 USB test (DMX interface) — the wizard offers ▶ Run the diagnostic (port, driver, actual transmission) and 💡 100% test, which sends full on across every channel.

One piece of software at a time on the box. A manufacturer utility or another lighting application holding the port makes the output erratic (flickering, “port not open”). Close everything else before connecting.

“Pro” USB interface (ENTTEC DMX USB Pro, Eurolite MK2)

macOS
This is the most reliable solution on Mac. The box generates the DMX signal itself : the output depends neither on the machine's load nor on the installed drivers.
1

Plug in before opening the window

Into a direct USB port (or a good-quality USB-C adapter). Plug it in before opening the DMX output window.

2

Do not install any driver

macOS ships its own FTDI driver. The box appears on its own as /dev/cu.usbserial-XXXXXXXX.

Do not add FTDI's VCP driver on top : it duplicates the ports and makes the selection ambiguous. If you have already installed it, uninstall it before troubleshooting.
3

Select and connect

Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🔌 USB DMX output :

  • Interface : “ENTTEC DMX USB Pro” or “Eurolite USB-DMX512 PRO (MK2)”.
  • COM port : the /dev/cu.usbserial-… entry (marked ★ for FTDI chips). The ↺ button re-runs the detection. The “COM port” label is carried over from Windows ; on Mac it does refer to the ports named cu.*.
  • 🔌 Connect — this is the button that actually switches the output over.
4

Check

The LED on the box turns green. For a full test : Connection ▸ 🩺 Diagnostics ▸ 🔌 USB test (DMX interface) ▸ ▶ Run the diagnostic, then 💡 100% test.

One piece of software at a time on the box : close every other lighting application or manufacturer utility before connecting.

“open” USB adapter (Open DMX, OPTO OPEN DMX, UltraDMX Micro, FTDI clones)

Windows
1

Close everything holding the chip

Manufacturer utility, another lighting application, a second instance of MyStrow : only one program can open the box. Two, and the output becomes erratic.

2

Select and connect

Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🔌 USB DMX output :

  • Interface : “ENTTEC Open DMX USB”, “OPTO OPEN DMX (ElectroConcept)”, “DMXKing UltraDMX Micro”, or “Other USB-DMX interface” for every FTDI clone.
  • COM port : FTDI chips are marked with a ★. The ↺ button rescans.
  • 🔌 Connect.
Once connected, the COM port may disappear from the list : that is normal, the chip is reserved for direct access. It comes back when you disconnect.
3

Box silent even though everything is green ? The RTS/DTR test

Connection ▸ 🩺 Diagnostics ▸ 🔌 USB test (DMX interface) ▸ 🔌 RTS/DTR test.

On these adapters, the pin that enables RS485 transmission is sometimes wired to the RTS or DTR control lines — and those are asserted by default when the port opens, which leaves the output completely silent, with no error. The test sweeps all four combinations, asks you which one lights the fixtures up, and the setting is remembered.

Before that, run the usual checks : 💡 100% test to send full on, with the master and the faders up, and a 120 Ω terminator at the end of the line.

“open” USB adapter (Open DMX, OPTO OPEN DMX, UltraDMX Micro, FTDI clones)

macOS
1

Plug in, install nothing

Direct USB port (or a quality USB-C adapter). macOS ships its FTDI driver : the box appears as /dev/cu.usbserial-XXXXXXXX.

Do not install FTDI's VCP driver on top of Apple's : it creates duplicate ports and muddles the selection.
2

What MyStrow does on Mac

On macOS, direct access to the chip (D2XX) is not available : MyStrow goes through the serial port and generates the DMX sync signal by toggling the baud rate. That is the method that actually works on Mac — the standard break command succeeds there without error but produces no valid electrical signal, which gives you a perfectly silent box and a perfectly green piece of software.

Nothing to adjust : it is automatic. Just remember that with this kind of box, the frame rate depends on the machine — for live work, a Pro interface remains safer.
3

Select and connect

Connection ▸ 🌐 DMX Output ▸ ⚙️ Configure output, tab 🔌 USB DMX output :

  • Interface : “ENTTEC Open DMX USB”, “OPTO OPEN DMX (ElectroConcept)”, “DMXKing UltraDMX Micro” or “Other USB-DMX interface”.
  • COM port : the /dev/cu.usbserial-…, marked ★. The ↺ button rescans.
  • 🔌 Connect.
4

Box silent even though everything is green ? The RTS/DTR test

Connection ▸ 🩺 Diagnostics ▸ 🔌 USB test (DMX interface) ▸ 🔌 RTS/DTR test.

The pin that enables RS485 transmission is sometimes wired to the RTS or DTR lines, which are asserted by default when the port opens : silent output, no error. The test sweeps all four combinations and remembers the one that lights your fixtures up.

Before that : 💡 100% test, master and faders up, 120 Ω terminator at the end of the line.
Multiple outputs

02 Universes and output routing

One universe = 512 channels = one XLR line. Beyond that — typically when you add moving heads — you have to spread the fixtures across several universes, which means a node with several outputs.

With the node connected, the DMX output window shows the Output routingtable : for each physical socket on the box (DMX 1 to DMX 4) you choose which universe is sent there, or Disabled.

ScenarioSettingResult
Standard install DMX 1 ← Universe 1, DMX 2 ← Universe 2, and so on. Each output carries its own universe.
Doubling a line (mirror) Two outputs on the same universe The same signal leaves on two sockets : both sides of the stage with no splitter.
Isolating a line while setting up The output set to Disabled The socket stops sending anything, the others carry on.

The patch stays in charge. Routing does not change the addressing : it is in the patch that each fixture gets its universe and its start address. Two devices whose ranges overlap will react together no matter what — the patch's ⚡ Auto-addressing function fixes that in one click.
