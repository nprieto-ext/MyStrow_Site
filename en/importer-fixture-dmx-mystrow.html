A DMX fixture (or fixture profile) describes exactly how your device works: how many channels it uses, what each channel controls (red, green, blue, strobe, pan, tilt…) and in what order. Without this profile, the software cannot send the right values to your hardware.

MyStrow ships with over 5,000 fixture profiles covering the major brands on the market — Chauvet, ADJ, Eurolite, Stairville, Robe, Martin, Showtec, Varytec and hundreds more. The vast majority of common fixtures are already there, with nothing to install.

Option 1 — The easiest

Download an XML profile from FixtureShare

The most complete and reliable place to find a free DMX fixture is FixtureShare, the official database of MA Lighting — one of the most respected console manufacturers in the industry.

FixtureShare MA Lighting

Thousands of verified fixture XML files, organised by brand and model. Free download, no account needed.

Open FixtureShare ↗
1

Search for your fixture

On fixtureshare.malighting.com, type the brand or model of your fixture in the search bar. You will get a list of matching files with their version and update date.

2

Download the XML file

Click the fixture that best matches your device (check the channel count and DMX mode in the description). Download the file — it has the .xmlextension. MyStrow supports the GrandMA XML format.

3

Import into MyStrow

In MyStrow, go to Admin Panel → Fixture library → Import (or use the File → Import fixture menu). Select the XML file you downloaded. The fixture appears immediately in your library, ready to use in your patch.

Tip: If your fixture has several modes (3 channels, 5 channels, 8 channels…), look for the file that contains every mode. In MyStrow you will pick the active mode directly in the fixture settings when patching.

💡 Can't find the file? If your fixture is not in the built-in library, look for it in .xml format on FixtureShare MA Lighting — it is almost always available.

Option 2 — For special cases

Building your own fixture in MyStrow

Got an exotic fixture, a custom-built device, or a machine whose manual matches no existing profile? MyStrow includes a fixture editor that lets you define your own profiles channel by channel, without leaving the app.

1

Open the fixture editor

In MyStrow, go to Admin Panel → Fixture library → New fixture (or click the “+” button). The editor opens with a blank profile.

2

Fill in the basic information

Enter the manufacturer name, the model name, and select the device type (LED PAR, moving head, LED bar, strobe…). This information is what you will use to find the fixture in the library later.

3

Define the DMX channels

Open your fixture's manual at the DMX channel table page. For each channel, state what it maps to: Dimmer, Red, Green, Blue, White, Amber, Strobe, Pan, Tilt… MyStrow has a predefined list of channel types covering every common use.

4

Save and use

Click Save. Your custom fixture is instantly available in the library, exactly like the 5,000 built-in fixtures. You can also export it as an .xml file to share or back it up.

Handy tip: Check your fixture's manual under “DMX Channel Configuration” or “DMX operating instructions”. Every DMX fixture has a table listing the channel, its function and the value ranges (0-255). That is all you need to build the profile.
