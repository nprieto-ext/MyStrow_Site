Create a lighting effect
in MyStrow

Chase, wave, even/odd flash, moving-head circle: everything is built in the effect editor by stacking layers. Here's how, column by column, with recipes to reproduce.

By MyStrow·Updated 18 November 2026
See the steps →All help ›
The principle

An effect = layers

Each layer animates one channel (intensity, colour, Pan/Tilt…) on a selection of fixtures, following a shape that repeats at a given speed. The offset between fixtures turns a simple blink into a chase or a wave.

An effect can contain several layers playing together. Once saved, effects stay available in MY EFFECTS.

Step by step

7 steps to create your effect

1

Open the effect editor

Menu Edit › 🎨 Effect editor. On the left, the list of effects (factory effects and MY EFFECTS), in the middle the layer table, on the right the lighting plan playing the preview.

2

Start from an existing effect… or from scratch

The quickest way: click a factory effect close to what you want, then Duplicate to work on a copy. To start from nothing: ＋ Add an effect › Create the effect myself (a blank layer is created).

3

Turn on live output

Click ⏺ Live output: your real fixtures play the effect while you adjust it. Turned off, the editor doesn't touch DMX and only the lighting plan shows the preview.

4

Set up the layer

Each row of the table is a layer: choose the TARGET (which fixtures), the CHANNEL (what moves) and the SHAPE (how it moves), then the speed, amplitude and offset. Each column is explained just below.

5

Stack layers

＋ Add a layer to animate another channel at the same time: for example intensity as a wave and a rotating colour, or a moving-head circle and a breathing dimmer.

6

Choose playback

Under PLAYBACK: 🔁 Loop (the usual case) or 1× Once (a single pass, useful for a shot or a single flash).

7

Assign and save

Under ASSIGN, click a button E1 to E8: the effect goes onto that effect button of the main window. Finish with Save effect. It joins MY EFFECTS.

The layer table

What each column does

Tip: clicking a column title selects it. A setting changed in one cell then applies to all layers.

ColumnRole
TARGETWhich fixtures play the layer: All, Even, Odd, or specific groups. Tip: click fixtures on the plan (1, 2, 3…) then Sel. to freeze a selection in that order.
CHANNELThe animated parameter: intensity (Dimmer), colour, Pan/Tilt, colour wheel… Only the patched fixtures that have this channel react.
SHAPEThe curve followed: Sine (smooth breathing), Flash (sharp hits), Triangle, Ramp up, Ramp down, One by one (only one fixture lit at a time), Random, Fixed, Off. On Pan/Tilt: the path (Circle, Eight, Infinity, Swing, Pendulum, Square).
SPDCycle speed, from 0 (very slow) to 100 (very fast). The mouse wheel adjusts in tenths: 29.8 is roughly 128 BPM.
AMPAmplitude: the maximum intensity reached. On Pan/Tilt, it's the width of the movement.
OFSOffset between fixtures: this is what creates the chase. 0 = all together, 180 = spread over one cycle.
GROUPNumber of fixtures that start together, in packs. 1 = one by one (classic chase).
DIROrder of travel: forward (1, 2, 3…), reverse, or back-and-forth.
FADESoftens the shape: 0 = hard transitions, 100 = soft fade. With the Ramp down shape, this is what creates a trail.
STARTShifts when this layer starts within the cycle, relative to the other layers.
MIN / MAXFloor and ceiling of the effect. MIN above 0: fixtures never go fully dark.
COL.The layer's colour(s) (colour channels only).
POSITION / SYMFor moving heads: the point the movement revolves around (a recorded position), and symmetry (Pan inverted, Tilt inverted) so that the heads on the right mirror those on the left.
Recipes

4 effects to reproduce

Chase

One fixture lights after another, in a loop.

  • CHANNEL: Dimmer
  • SHAPE: One by one
  • DIR: forward, or back-and-forth for a scanner look
  • SPD: to the tempo

Smooth wave

Intensity ripples from one side of the stage to the other.

  • CHANNEL: Dimmer
  • SHAPE: Sine
  • OFS: 180 (spread over one cycle)
  • MIN: 20 so it never goes to black

Even / odd

Half the fixtures flash, then the other half.

  • Layer 1: TARGET Even, CHANNEL Dimmer, SHAPE Flash
  • Layer 2: TARGET Odd, same settings, START at 50 (half a cycle later)

Mirrored moving-head circle

The heads draw a circle, stage left and stage right in symmetry.

  • CHANNEL: Pan/Tilt
  • SHAPE: Circle
  • POSITION: your “audience” or “stage” position
  • SYM: Pan inverted
  • AMP: small to start with, then widen

For a strobe, no need to build one: the factory effects include one (“Strobe Classique”) that you can duplicate and adapt. File › ⚡ Load default effects puts the basic effects back on the E buttons.

Troubleshooting

Frequently asked questions

The effect runs in the editor but my fixtures don't move.

Turn on ⏺ Live output in the editor. Also check that your fixtures have the animated channel (a PAR without Pan/Tilt will never play a circle) and that the TARGET includes them.

How do I trigger the effect during the show?

Assign it to a button E1 to E8 from the editor (ASSIGN section), then press that button in the main window or on the controller. Right-clicking an effect button lets you configure it.

I've messed up a factory effect.

Select it and click ↺ Restore factory version. The ↺ Reset ALL factory effects button does the same for the whole list.

Can I share an effect?

Yes: Export creates a .mystrow_effect file, which the other person adds with ＋ Add an effect › Import an effect.

I want to lock the effect to the music's tempo.

Set SPD with the mouse wheel: one notch = one tenth, and 29.8 is roughly 128 BPM. The controller's TAP button also lets you tap the tempo.
