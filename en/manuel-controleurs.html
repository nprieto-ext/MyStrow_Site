Controllers
and shortcuts

MyStrow can be played with the mouse, but it's nicer under your fingers. This chapter covers every way to drive it: MIDI and DJ controllers, Stream Deck, lighting console and keyboard. The game controller is in the Moving heads chapter, the tablet in the next chapter.

MIDI controllers recognised out of the box

The AKAI APC mini mk2 is the reference controller: its pad grid and faders match MyStrow's surface exactly (see the Live playing chapter). The Novation Launchpad Mini MK3 is also recognised, as are the profiles shared by the community.

  1. Plug the controller in over USB before or after launch: MyStrow detects it on its own.
  2. To check: Connection › 🎮 Control › 🎹 Contrôleur MIDI (MIDI controller).
  3. To change what each column does, the pages and the bottom-right button: ⚙️ Controller settings.

On Windows, only one program at a time can use a MIDI controller: close other programs that have it open.

Another controller: the “My controller isn't recognised” wizard

For any other MIDI controller (or a DJ controller whose pads you want to use), open Connection › 🎮 Control › 🎹 Contrôleur MIDI and choose to add a controller: the wizard creates its profile in a few minutes.

  1. New controller: give it a name and choose its MIDI port. Tick My controller is a DJ controller for a DJ controller (only the pads are used).
  2. Controller layout: number of pad rows and columns, faders and effect buttons.
  3. Pad mapping: press each pad shown; then Fader mapping: move each fader from bottom to top; then the Effect buttons.
  4. LED test: MyStrow works out how to light your model's pads, and you click the colour you see.
  5. ✅ Use my controller now: the profile is installed and reloaded at every startup.

Optionally, Share with the community sends the profile for review; it's then offered automatically to everyone who plugs in the same model. Export to a file… backs it up.

Elgato Stream Deck

Connection › 🎮 Control › 🎛️ Stream Deck installs the MyStrow plugin for the Elgato Stream Deck software (Install plugin). Then restart the Stream Deck software and look for MyStrow in the right-hand column to drag its actions onto your keys. MyStrow must be running for the keys to respond.

Driving MyStrow from a lighting console (DMX input)

Connection › 🎮 Control › 🎚️ DMX input (console): a lighting console controls MyStrow's groups, memories and effects over DMX or Art-Net. This needs an Art-Net node with one port set as input (see output routing in the DMX output chapter).

  • Enable DMX input, then fill in the DMX channel → Strip table.
  • Default patch: channels 1 to 7 → groups A to G, channels 8 to 106 → MEM 1 to MEM 99.
  • A channel can also drive the effect speed or the player volume.

Keyboard shortcuts

Connection › ⌨️ Keyboard shortcuts: click a shortcut, then type the new key combination. ✕ clears it, ↺ restores the default. Save your settings as a preset to switch between configurations; ↺ Restore defaults resets everything.

A few fixed shortcuts worth knowing: Space for play / pause, Ctrl+PageDown / Ctrl+PageUp to change pad page, Ctrl+Z / Ctrl+Y in the patch and the timeline.

Frequently asked questions

My AKAI isn't detected.

Try another cable or USB port, close any other program using the controller, then open Connection › 🎮 Control › 🎹 Contrôleur MIDI (MIDI controller).

My controller isn't in the list.

Use the “My controller isn't recognised” wizard: you just press each pad and move each fader. The profile is then permanent on that computer.

Can I use two controllers at once?

A MIDI controller drives the pad surface; you can add a tablet, a game controller, a Stream Deck and the keyboard, which all work in parallel.
