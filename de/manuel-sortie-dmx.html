DMX-Ausgang:
MyStrow mit den Scheinwerfern verbinden

Damit MyStrow echte Scheinwerfer steuert, braucht es ein DMX-Interface zwischen Computer und erstem Scheinwerfer. Dieses Kapitel behandelt alles in Verbindung › 🌐 DMX-Ausgang und die Testwerkzeuge.

Das Prinzip: Computer → Interface → Scheinwerfer

Ein Computer gibt von sich aus kein DMX aus. Man schließt ein Interface an:

  • per USB: eine USB-DMX-Box (ENTTEC, Eurolite, Open DMX…);
  • über das Netzwerk: einen Art-Net-Node per Ethernet (RJ45), direkt oder über einen Switch.

Vom Interface führt ein DMX-Kabel (XLR) zum ersten Scheinwerfer, dann von Scheinwerfer zu Scheinwerfer. Eine DMX-Linie = ein Universum = 512 Kanäle. MyStrow verwaltet bis zu 4 Universen.

Während der 15-tägigen Testphase funktioniert der DMX-Ausgang. Danach braucht er eine aktive Lizenz.

Das Fenster DMX-Ausgang öffnen

Menü Verbindung › 🌐 DMX-Ausgang. Das Fenster fragt zuerst, welches Interface Sie haben, mit drei Möglichkeiten, die man an der Lage des gelben Logos erkennt:

  • MyStrow-Logo auf der Vorderseite: Das ist der USB NODE DMX (ElectroConcept), die Box im MyStrow-Pack. Er wird per USB angeschlossen, spricht aber Art-Net: MyStrow richtet ihn selbst im Node-Ausgang ein, ohne IP-Adresse.
  • MyStrow-Logo oben: Das ist das MyStrow USB-DMX (MS-DMY). Per USB anschließen, MyStrow findet es selbst. Wurde es gerade eingesteckt, klicken Sie auf 🔌 Verbinden.
  • Anderes Interface: der vollständige Bildschirm mit zwei Registerkarten, 🌐 Node-Ausgang und 🔌 USB-DMX-Ausgang.

USB-DMX-Interface (Registerkarte USB-DMX-Ausgang)

  1. Schließen Sie das Interface per USB an (am besten direkt am Computer, ohne Hub).
  2. Wählen Sie unter Interface Ihr Modell: MyStrow USB-DMX (MS-DMY), Eurolite USB-DMX512 PRO (MK2), ENTTEC DMX USB Pro, ENTTEC Open DMX USB, OPTO OPEN DMX (ElectroConcept), DMXKing UltraDMX Micro oder Andere USB-DMX-Schnittstelle.
  3. Wählen Sie den COM-Port, der beim Einstecken erscheint.
  4. Klicken Sie auf 🔌 Verbinden. Bei den meisten Interfaces leuchtet eine LED grün, wenn der DMX-Ausgang aktiv ist.

Steht auf Ihrer Box Art-Net, Node oder RDM? Auch per USB angeschlossen wird sie hier nicht eingerichtet: Nutzen Sie die Registerkarte Node-Ausgang. Das gilt für den USB NODE DMX.

„Port nicht verfügbar“: Ein anderes Programm (QLC+, Freestyler, Chataigne…) belegt das Interface. Schließen Sie es: Nur ein Programm gleichzeitig kann es nutzen.

Ein USB-Interface überträgt nur ein Universum. Mehrere USB-Interfaces ergeben keine mehreren Universen: Dafür braucht es Art-Net-Nodes.

Für ein Open DMX oder ein Interface mit FTDI-Chip installieren Sie den FTDI-Treiber, wenn MyStrow ihn anbietet.

Art-Net-Node (Registerkarte Node-Ausgang)

  1. Verbinden Sie den Node per Ethernet-Kabel mit dem Computer (für DMX kein WLAN).
  2. Prüfen Sie unter Netzwerkkarte die mit dem Node verbundene Karte.
  3. Wählen Sie unter Art-Net-Node Ihren Node aus den Geräten, die geantwortet haben, oder geben Sie seine IP-Adresse ein. Netzwerk erneut durchsuchen wiederholt die Suche.
  4. Klicken Sie auf 🔌 Verbinden.

Das Netzwerk muss im selben Bereich wie der Node liegen. Viele Art-Net-Nodes nutzen 2.x.x.x (ElectroConcept-Boxen sind ab Werk auf 2.0.0.15 eingestellt), andere 192.168.x.x. Die Schaltfläche ⚙️ Netzwerkverbindung konfigurieren startet einen Assistenten, der:

  • Sie die mit der Box verbundene Netzwerkkarte wählen lässt (nicht das WLAN);
  • den Computer auf 2.0.0.1 / Maske 255.0.0.0 stellt, entweder automatisch (Administratorrechte nötig: 🔑 Als Administrator neu starten) oder von Hand mit Ich konfiguriere selbst, das die Windows-Schritte zeigt;
  • die Verbindung testet und bestätigt, dass die Box verbunden ist.

Findet MyStrow die Box unter einer anderen Adresse als gesucht, meldet es das und bietet eine Schaltfläche [Adresse] verwenden an: Ein Klick genügt, am Netzwerk ist nichts zu ändern.

Beim ersten Start lassen Sie MyStrow durch die Firewall, wenn Windows fragt: Sonst wird der Node nicht gefunden.

Mehrere Universen und mehrere Nodes

In der Registerkarte Node-Ausgang zeigt Erweiterte Optionen › Zuordnung der Ausgänge für jede DMX-Linie, welches Universum darauf ausgegeben wird und an welchen Node.

  • Node mit 2 oder 4 Ausgängen: Eine Box genügt, jeder Ausgang trägt sein Universum.
  • Mehrere Nodes mit 1 Ausgang: Geben Sie jedem Node seine eigene IP-Adresse und sein Art-Net-Universum (mit dem Programm des Herstellers) und wählen Sie in jeder Tabellenzeile den richtigen Node.
  • Zwei Linien können dasselbe Universum tragen: Das ist die Spiegelung, um eine Linie am anderen Ende des Saals ohne Splitter zu verdoppeln.
  • Eine Linie kann deaktiviert sein oder als DMX-Eingang (Pult) dienen, um MyStrow von einem Lichtpult aus zu steuern.

Setzen Sie dann im Patch jeden Scheinwerfer in das Universum der Linie, an der er hängt (die Adressen beginnen in jedem Universum wieder bei 1). Vollständige Anleitung: mehrere Universen mit mehreren Art-Net-Nodes.

Den Ausgang testen: DMX-Tester und DMX-Monitor

Bearbeiten › 🔬 DMX-Tester sendet Werte direkt auf Kanäle, am Patch vorbei. Damit stellt man fest, ob ein Scheinwerfer DMX empfängt:

  • wählen Sie das DMX-Universum, klicken und ziehen Sie auf den Kanälen, um ihren Wert einzustellen (Strg = mehrere Kanäle, Umschalt = ein Bereich, Mausrad = ±5);
  • Schaltflächen heben oder senken alle 512 Kanäle auf einmal;
  • GRUPPENTEST schaltet Kanäle paketweise ein (Kanäle pro Gruppe einstellen, dann ▶▶ Die nächsten senden), um die Adresse eines Scheinwerfers zu finden;
  • die Fader des MIDI-Controllers steuern jeweils 9 Kanäle;
  • beim Schließen wird die Show wiederhergestellt.

Bearbeiten › 📡 DMX-Monitor zeigt live, was tatsächlich auf jedem Universum ausgegeben wird: aktive Kanäle, Bilder pro Sekunde, genutztes Interface und eine Warnung, wenn ein Universum nicht gesendet wird (zum Beispiel Universum 2 an einem USB-Interface, das nur Universum 1 überträgt).

Einen stummen Ausgang diagnostizieren

Menü Verbindung › 🩺 Diagnose:

  • 🌐 RJ45-Test (Netzwerk / Art-Net-Node): prüft Kabel, Netzwerkkarte, IP-Adresse und Antwort der Box und bietet an, Fehler zu beheben;
  • 🔌 USB-Test (DMX-Interface): prüft das USB-Interface und seinen Port;
  • 🩺 Vollständige Diagnose (BRAD): führt alle Tests des Art-Net-Ausgangs durch. 📋 Bericht kopieren oder ✉️ An den Support senden schickt uns das Ergebnis.

Die häufigsten Ursachen, in dieser Reihenfolge:

  1. ein anderes Lichtprogramm ist geöffnet und belegt das Interface;
  2. ein USB-Art-Net-Interface (USB NODE) wird in der USB-Registerkarte statt im Node-Ausgang gesucht;
  3. Computer und Node nicht im selben IP-Bereich, oder die Firewall blockiert;
  4. der Scheinwerfer steht nicht auf der Adresse oder im DMX-Modus des Patches (DMX geht raus, aber der Scheinwerfer hört woanders): Der DMX-Tester zeigt das sofort;
  5. defektes USB-Kabel, defekter Port oder defektes DMX-Kabel.

Auf dem Mac: Ist der Ausgang auf „USB“ geblieben, obwohl Sie einen Node nutzen, öffnen Sie den DMX-Ausgang erneut und wählen Sie Art-Net.

Häufige Fragen

Welches DMX-Interface sollte ich für MyStrow kaufen?

Jedes handelsübliche USB-DMX-Interface oder jeder Art-Net-Node funktioniert. Am einfachsten ist das MyStrow-Pack (Interface + Lizenz): MyStrow erkennt und richtet es selbst ein. Für mehr als ein Universum nehmen Sie einen Art-Net-Node.

Wie viele Scheinwerfer kann ich steuern?

Ein Universum hat 512 Kanäle, MyStrow verwaltet bis zu 4 Universen (2.048 Kanäle). Die Anzahl der Scheinwerfer hängt von ihrer Kanalzahl ab: Ein PAR mit 7 Kanälen belegt 7, ein Moving Head mit 16 Kanälen belegt 16.

Reicht WLAN für einen Art-Net-Node?

Möglich, aber nicht empfohlen: WLAN bringt Aussetzer und Verzögerung. Verbinden Sie den Node per Ethernet-Kabel, direkt oder über einen Switch.

Mein Interface wird erkannt, aber nichts leuchtet.

Öffnen Sie Bearbeiten › 🔬 DMX-Tester und heben Sie die Kanäle des Scheinwerfers an. Leuchtet er, funktioniert der Ausgang: Adresse oder DMX-Modus im Patch passen nicht zum Scheinwerfer. Bleibt er dunkel, prüfen Sie das DMX-Kabel und starten Sie Verbindung › 🩺 Diagnose.
