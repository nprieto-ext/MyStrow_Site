Ihr Licht folgt
der Videoregie

Wenn in OBS eine Szene auf Sendung geht oder in vMix eine Kamera auf Program, schickt MyStrow das passende Licht. Die Regie führt, das Licht folgt — ohne dass jemand am Pult sitzt.

Das Prinzip

Ein Video-Ereignis, eine Licht-Aktion

Ob OBS oder vMix, das Prinzip ist dasselbe — und MyStrow wird auf die gleiche Weise angebunden. Ihre Regie meldet ständig, was auf Sendung ist: die aktive Szene in OBS, den Eingang auf Program in vMix. MyStrow hört dieses Signal ab und löst die Aktion aus, die Sie dieser Quelle zugeordnet haben.

Konkret: Die Totale geht auf Sendung → das Frontlicht fährt hoch. Sie schneiden auf die Kamera des Schlagzeugers → das Gegenlicht wird blau. Der Abspann startet → die Cartouche „Ende des Sets“ läuft von selbst. Während der Sendung gibt es nichts zu klicken.

Die Verbindung ist einseitig: Die Regie steuert MyStrow, nie umgekehrt. Das ist eine bewusste Entscheidung. Die Regie führt die Sendung, und eine Verbindung in beide Richtungen würde eine Rückkopplungsschleife öffnen — MyStrow wechselt einen Speicher, die Regie meldet ein Ereignis zurück, MyStrow spielt die Aktion erneut ab —, die man dann erst bändigen müsste.

Alles läuft über das Netzwerk. Wenn Ihre Regie und MyStrow auf demselben Computer laufen, gibt es absolut nichts anzuschließen.

Was MyStrow auslösen kann

Drei Arten von Aktionen

🎚

Ein Speicher

Ein kompletter Lichtzustand, gespeichert auf einem MEM-Pad. Das ist die häufigste Wahl: jede Kamera mit ihrer eigenen Stimmung. Der Speicher wird genau so abgerufen, als hätten Sie das Pad gedrückt.

✨

Ein Effekt

Einer der Effekte Ihrer Tasten E1 bis E9: Lauflicht, Strobe, Regenbogen, Moving-Head-Bewegung. Praktisch für eine Stimmungseinstellung oder einen Höhepunkt, der jedes Mal wiederkommt.

🔊

Eine Cartouche

Ein Sound, gestartet zusammen mit der Einstellung. Eröffnungsjingle, Soundlogo, Klangteppich — ausgelöst durch das Video, ohne das Licht aus den Augen zu lassen.

⏸

Nichts

Eine Quelle kann auch gar keine Aktion haben. Zwischenszenen, Testbilder, technische Einstellungen: Lassen Sie sie auf „Nichts“, dann bleibt das aktuelle Licht unverändert.

Ausgelöst wird bei der steigenden Flanke. Die Aktion startet nur in dem Moment, in dem die Quelle aktiv wird. Solange sie auf Sendung bleibt, wird nichts wiederholt — Sie können also während der Einstellung am Pult übernehmen, ohne dass MyStrow Sie eine Sekunde später überschreibt.

OBS Studio

OBS mit MyStrow verbinden

Seit Version 28 bringt OBS einen obs-websocket-Server mit, ganz ohne Plugin. Er ist integriert, aber standardmäßig deaktiviert: Daran scheitert fast jede erste Einrichtung.

1

Den Server in OBS aktivieren

In OBS: Werkzeuge → WebSocket-Servereinstellungen. Kreuzen Sie „WebSocket-Server aktivieren“ an und klicken Sie auf Übernehmen. Notieren Sie den Port, standardmäßig 4455. Ohne dieses Häkchen kann MyStrow nichts erreichen.

2

Das Passwort notieren

Klicken Sie im selben Fenster auf „Verbindungsinformationen anzeigen“. OBS zeigt dort ein automatisch erzeugtes Passwort an. Kopieren Sie es. Wenn Sie darauf verzichten möchten, entfernen Sie das Häkchen bei „Authentifizierung aktivieren“ — in einem geschlossenen Regie-Netzwerk ist das vertretbar.

3

Das OBS-Fenster von MyStrow öffnen

In MyStrow: Verbindung → 🎮 Steuerung → 🎬 OBS Studio. Lassen Sie den Host auf 127.0.0.1, wenn OBS auf demselben Computer läuft, und fügen Sie das Passwort ein. Die Schaltfläche Suchen findet die Adresse selbst, wenn Ihre Regie auf einem anderen Rechner im Netzwerk läuft.

4

Die Verbindung testen

Klicken Sie auf Verbindung testen. Die Tabelle füllt sich mit der Liste Ihrer OBS-Szenen, in derselben Reihenfolge wie in OBS. Erscheint nichts, sehen Sie in der Fehlertabelle weiter unten nach — die angezeigte Meldung nennt die Ursache.

5

Szenen und Aktionen zuordnen

Wählen Sie für jede Szene den Aktionstyp und dann das Ziel: Speicher 3.2, Effekt E4, Cartouche 1 … Szenen, die nichts auslösen sollen, bleiben auf „— Nichts —“.

6

„OBS-Verbindung aktivieren“ ankreuzen

Unten im Fenster, dann Speichern. Erst dieses Häkchen schaltet die Verbindung ein: Die Einstellungen allein lösen nichts aus. MyStrow verbindet sich beim nächsten Start von selbst wieder.

💡 Die von OBS angezeigte Adresse ist nicht die, die Sie übernehmen sollten. Das Fenster mit den Verbindungsinformationen zeigt eine Adresse wie 192.168.1.x: Sie ist für ein anderes Gerät gedacht, ein Handy oder einen zweiten Rechner. Vom selben Computer aus führt 127.0.0.1 zum selben OBS — und diese Adresse ändert sich nicht, wenn Ihr Router neue vergibt.

vMix

vMix mit MyStrow verbinden

Bei vMix geht es schneller: MyStrow nutzt die TCP-API auf Port 8099, die immer aktiv ist. Es gibt weder einen Server zu aktivieren noch ein Passwort einzugeben.

Genau deshalb wurde dieser Port der Web-API (8088) vorgezogen: Der Web Controller kann deaktiviert sein, Port 8099 nicht. Eine Abhängigkeit weniger, die man am Abend der Show prüfen muss.

1

Das vMix-Fenster von MyStrow öffnen

In MyStrow: Verbindung → 🎮 Steuerung → 🎥 vMix. Der Host ist 127.0.0.1, wenn vMix auf demselben PC läuft, der Port 8099. Die Schaltfläche Suchen sucht vMix im lokalen Netzwerk, wenn Ihre Regie woanders steht.

2

Die Verbindung testen

Klicken Sie auf Verbindung testen: MyStrow liest die Liste Ihrer vMix-Eingänge und füllt die Tabelle. Jede Zeile zeigt Nummer und Namen des Eingangs, so wie vMix sie meldet.

3

Eingänge und Aktionen zuordnen

Gleiches Prinzip wie bei OBS: für jeden Eingang ein Aktionstyp und ein Ziel. MyStrow folgt dem Program-Tally — die Aktion startet, wenn der Eingang auf Sendung geht, nicht wenn er in der Preview landet.

4

„vMix-Verbindung aktivieren“ ankreuzen

Dann Speichern. Die Verbindung stellt sich bei jedem Start selbst wieder her und verbindet sich von allein neu, wenn vMix während des Aufbaus neu gestartet wird.

Preview oder Program? Nur der Wechsel auf Program löst die Aktion aus. Ein Eingang in der Preview ändert nichts am Licht: Sie können Ihre nächste Einstellung in Ruhe vorbereiten, das Publikum merkt nichts.

Gut zu wissen

Ein Unterschied, der zählt

Die beiden Regien bezeichnen ihre Quellen nicht auf die gleiche Weise, und das hat ganz konkrete Folgen für Ihre Zuordnungen.

OBS — erkannt am NAMEN

Das Umsortieren Ihrer Szenen macht nichts kaputt: Verschieben Sie sie nach Belieben. Eine Szene umzubenennen, löst dagegen die Zuordnung — die Aktion startet nicht mehr. Ordnen Sie sie in der Tabelle einfach neu zu.

vMix — erkannt an der NUMMER

Hier ist es umgekehrt: Benennen Sie Ihre Eingänge frei um. Aber eine geänderte Reihenfolge verschiebt die Zuordnungen, und das Licht der Totalen startet dann bei Kamera 2. Prüfen Sie die Tabelle nach jedem Umbau.

Der Handgriff, der böse Überraschungen verhindert: Nachdem Sie Reihenfolge oder Namen Ihrer Quellen geändert haben, öffnen Sie das Verbindungsfenster erneut und starten „Verbindung testen“ noch einmal. Die Liste wird aktualisiert und Sie sehen sofort die Zeilen, die ins Leere zeigen.

Fehlerbehebung

Es verbindet sich nicht

MyStrow zeigt unter den Verbindungsfeldern eine genaue Meldung an. In der App sind diese Meldungen auf Französisch — hier steht, was sie jeweils bedeuten.

Die Verbindung steht, aber nichts wird ausgelöst

  • Ist „Verbindung aktivieren“ angekreuzt? Die Zuordnungen sind gespeichert, bleiben aber wirkungslos, solange die Verbindung nicht eingeschaltet ist.
  • Haben Sie auf Speichern geklickt? Wird das Fenster anders geschlossen, gehen die Änderungen verloren.
  • Zeigen die Zeilen noch irgendwohin? Eine in OBS umbenannte Szene, umsortierte vMix-Eingänge: Starten Sie „Verbindung testen“ erneut, um die Liste zu aktualisieren.
  • Gibt es den Zielspeicher noch? Eine Aktion, die auf einen gelöschten Speicher verweist, bewirkt nichts.
  • Erwarten Sie eine Auslösung bei der Preview? Nur der Wechsel auf Program wirkt.

Kommen Sie nicht weiter? Schreiben Sie uns über Kontakt und nennen Sie die genaue Meldung von MyStrow, Ihre OBS- oder vMix-Version und ob beide Programme auf demselben Rechner laufen. Diese drei Angaben reichen fast immer aus.
