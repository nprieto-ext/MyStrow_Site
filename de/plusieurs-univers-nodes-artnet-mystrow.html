Ein Universum
pro Node

Ihre Anlage braucht mehr als 512 Kanäle, oder Ihre Scheinwerfer hängen an zwei Stellen im Saal? Schließen Sie pro Universum einen Art-Net-Node an und sagen Sie MyStrow, welcher was bekommt. Bis zu vier Universen, ohne Lichtpult.

Von MyStrow · Veröffentlicht am 7. Oktober 2026 · ⏱ Lesezeit: 5 Min.
Die Einrichtung → Was nicht geht →
Das Prinzip

Ein Universum = 512 Kanäle = ein DMX-Kabel

Ein DMX-Universum überträgt 512 Kanäle. Ein Moving Head im 16-Kanal-Modus belegt sechzehn, eine Pixel-LED-Leiste über hundert: Die Grenze ist schnell erreicht. Die Lösung ist ein zweites Universum, also eine zweite DMX-Linie mit eigenen 512 Kanälen.

MyStrow verwaltet vier Universen. Bei einem Art-Net-Node mit vier Ausgängen trägt jeder Ausgang bereits ein Universum. Viele kompakte Nodes — etwa die Art-Net POE mit einem Universum von Electroconcept — haben aber nur einen. Dann nimmt man einen Node pro Universum, alle im selben Netzwerk, und MyStrow sendet jedem sein eigenes.

Verfügbar ab MyStrow 3.2.2. Ältere Versionen schickten alle vier Universen an ein einziges Gerät: Der zweite Node blieb stumm.

Die Hardware

Was Sie brauchen

  • Einen Art-Net-Node pro Universum — RJ45 oder POE.
  • Einen Netzwerk-Switch zwischen PC und Nodes. Bei POE-Nodes versorgt ein POE-Switch sie über das Netzwerkkabel mit Strom.
  • Das Herstellerprogramm, um IP-Adresse und Universum jedes Nodes einzustellen (DMX TOOLS bei Electroconcept).
  • Ein Netzwerkkabel pro Node, plus eines für den PC.
Die Einrichtung

Vier Schritte

1

Geben Sie jedem Node eine eigene IP-Adresse

Nodes desselben Modells kommen mit derselben Adresse ab Werk: Zwei im selben Netz stören sich. Stellen Sie sie mit dem Herstellerprogramm z. B. auf 2.0.0.15, 2.0.0.16, 2.0.0.17 … ein. Immer nur ein Gerät angeschlossen.

2

Stellen Sie das Universum jedes Nodes ein

Der erste Node auf Art-Net-Universum 0, der zweite auf Universum 1 usw. Diese Nummer zeigt MyStrow in der Spalte „Art-Net“ der Tabelle. Manche Programme zählen ab 1: Bleibt ein Node stumm, ist das das Erste, was Sie prüfen sollten.

3

Ordnen Sie jede Zeile ihrem Node zu

Öffnen Sie in MyStrow Verbindung ▸ DMX-Ausgang, Reiter Node-Ausgang, und klicken Sie auf ↻, um die Nodes zu finden. Wählen Sie den ersten als Haupt-Node. In der Tabelle „Zuordnung der Ausgänge“, Spalte An Node gesendet, wählen Sie in Zeile DMX 2 den zweiten Node, in Zeile DMX 3 den dritten … und klicken Sie auf Verbinden.

4

Patchen Sie Ihre Scheinwerfer ins richtige Universum

Im Patch kommen die am ersten Node verkabelten Scheinwerfer in Universum 1, die am zweiten in Universum 2. Die DMX-Adressen beginnen in jedem Universum wieder bei 1.

Beispiel

Vier Nodes, vier Universen

ZeileMyStrow-UniversumArt-Net-UniversumNodeIP-Adresse
DMX 1Universum 10Node 12.0.0.15
DMX 2Universum 21Node 22.0.0.16
DMX 3Universum 32Node 32.0.0.17

Eine Zeile kann auch dasselbe Universum wie eine andere senden: Das ist der Spiegelmodus, praktisch, um eine DMX-Linie am anderen Ende des Saals ohne Splitter zu verdoppeln.

Die Grenzen

Was nicht geht

HardwareMehrere Universen?Warum
Art-Net-Nodes RJ45 oder POE✅ Bis zu 4Jeder hat seine eigene Netzwerkadresse: MyStrow sendet jedem Node sein Universum.
Art-Net-Node mit 2 oder 4 Ausgängen✅ Bis zu 4Ein Gerät genügt: Jeder Ausgang trägt bereits ein Universum.
USB-DMX-Interfaces (Open DMX, Enttec, MS-DMX …)❌ Nur einesMyStrow steuert immer nur einen USB-Port. Vier Interfaces ergeben keine vier Universen.
Mehrere USB NODE von Electroconcept⚠️ Nicht empfohlenJedes Gerät legt eine eigene Netzwerkkarte an, alle mit derselben Werksadresse: Der PC weiß nicht mehr, mit wem er sprechen soll.
Fehlersuche

Wenn ein Node stumm bleibt

  • Der zweite Node leuchtet nicht: Prüfen Sie, ob sein Universum der „Art-Net“-Nummer seiner Zeile entspricht. Zählt das Programm ab 1, versuchen Sie die nächste Nummer.
  • Nur ein Node antwortet auf die Suche: Beide haben wahrscheinlich dieselbe IP-Adresse. Ändern Sie eine, nur dieses Gerät angeschlossen.
  • Die Scheinwerfer an Node 2 reagieren auf die Einstellungen von Node 1: Sie sind im falschen Universum gepatcht. Öffnen Sie den Patch und setzen Sie sie auf Universum 2.
  • Kein Node antwortet: Die Netzwerkkarte des PCs muss im Netz 2.x.x.x liegen. Die Anleitung zur Node-Einrichtung erklärt diese Einstellung.
