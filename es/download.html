Compatibilidad

Windows & macOS

MyStrow esta disponible en Windows 10/11 y macOS 11+. Ambas versiones reciben las mismas actualizaciones.

Windows
  • Windows 10 / Windows 11
  • 4 GB de RAM minimo
  • 500 MB de espacio en disco
  • Salida DMX: interfaz USB o nodo Art-Net (red)
  • Protocolo DMX Art-Net (UDP 6454)
↓ Descargar para Windows

macOS
  • macOS 11 Big Sur o superior
  • 4 GB de RAM minimo
  • 500 MB de espacio en disco
  • Salida DMX: interfaz USB o nodo Art-Net (red)
  • Apple Silicon & Intel compatibles
